## Preview and media

Run `python -m http.server 4173 --bind 127.0.0.1` from this directory and open `http://127.0.0.1:4173/`. Videos use H.264 MP4 with fast-start metadata and load when visitors select a demo. Closing the dialog stops and unloads the recording and returns focus to its launch link. Native MP4 links remain available without JavaScript.
